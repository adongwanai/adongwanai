
## Research & Engineering Themes

<div align="center">

`Agent Memory` · `Router Harness` · `Skills Self-Evolution` · `Agentic RL` · `Long-Horizon Eval`

</div>

- **Memory**：长期画像、用户规则、工作区与 episodic / semantic memory；关注写入、选择、压缩、隔离和跨会话保持。
- **Harness**：Dispatch、Tool Calling、Interrupt / Resume、Verifier、Checkpoint、Artifact 与权限边界。
- **Routing**：端侧状态与权限常驻，复杂步骤按需调用云端模型，综合质量、成本、时延与隐私进行选择。
- **Evaluation**：办公长程任务、技能迁移、记忆保持、工具调用可靠性与失败模式归因。
